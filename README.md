Program Belanja merupakan program sederhana berbasis Java yang digunakan untuk menghitung total harga dan jumlah barang yang dibeli. Pengguna dapat memasukkan harga barang secara berulang, kemudian memilih apakah ingin melanjutkan belanja atau tidak. Setelah selesai, program akan menampilkan total harga seluruh barang dan jumlah barang yang telah dimasukkan. Program ini menggunakan Scanner untuk menerima input dan perulangan while untuk mengulang proses pembelian
